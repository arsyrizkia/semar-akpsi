# Audit antarmuka SEMAR (22 Okt 2026)

Audit akhir atas semua berkas antarmuka yang berubah pada putaran perombakan layar dan modal (`src/app/**`,
`src/components/**`, `globals.css`). Acuan: pre-delivery checklist `ui-ux-pro-max` (`docs/desain-sistem.md` bagian 7;
berkas `references/pro-rules.md` tidak ada di repo) dan aturan `web-design-guidelines` yang diambil dari
https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md pada 23 Okt 2026.

Caranya: pembacaan kode oleh setiap agen, pencarian pola otomatis (grep) oleh perakit, lalu pemeriksaan perilaku lewat
e2e (puppeteer, lebar 1440 dan 390 px) dengan tangkapan layar di `docs/bukti-e2e/`.

## Hasil pencarian pola (seluruh `src/`)

| Aturan | Pola yang dicari | Hasil |
|---|---|---|
| Fokus terlihat | `outline-none` tanpa `focus-visible` | Tidak ada. Cincin fokus global di `globals.css` (emas, halo krem). |
| Animasi | `transition-all`; `prefers-reduced-motion` | `transition-all` tidak ada; aturan reduced-motion global mematikan animasi dan transisi. |
| Elemen interaktif | `<div onClick>` / `<span onClick>` | Tidak ada; tombol memakai `<button>`, navigasi memakai `<a>`/`Link`. |
| Gambar | `<img>` tanpa `alt` | Tidak ada `<img>` di antarmuka (ilustrasi SVG inline, dekoratif `aria-hidden`). |
| Tipografi | `...` pada teks status | Tidak ada; status memuat memakai "…". |
| Font merek | Cormorant / `font-serif` | Tidak ada. Outfit lewat `next/font` (`--font-outfit`) untuk wordmark, judul, dan teks UI. BIMA tiruan sengaja memakai font sistem agar tampak sebagai sistem lain. |
| Isian | `<input>`/`<textarea>` tanpa `autoComplete` | Hanya input tersembunyi, kotak centang, dan berkas (tidak berlaku). Isian teks memakai `name`, label, dan galat inline lewat komponen bersama `Isian`/`Pilihan`. |
| Sentuh | `touch-action: manipulation` | Global di `globals.css`. |
| Aria-live | status asinkron | 27 pemakaian `role="status"`/`role="alert"`/`aria-live` (galat formulir, hasil asinkron, toast). |
| Peringatan keluar | perubahan belum disimpan | `beforeunload` di J-02b (`form-susun.tsx`) dan J-08b (`keputusan-klien.tsx`). |
| Tema | `color-scheme`, `theme-color` | `viewport` di `layout.tsx`: `themeColor` krem, `colorScheme: light`. |

## Daftar periksa per kelompok

| Kelompok | Status | Catatan |
|---|---|---|
| Aksesibilitas | Lulus | Skip link "Lewati ke isi"; heading berurutan h1 lalu h2; tombol ikon berlabel; ikon dekoratif `aria-hidden`; tabel dengan `aria-label`/`caption`; status = teks + ikon + warna (bukan warna saja). |
| Modal (M-01..M-11) | Lulus | Radix Dialog: fokus terjebak, Esc menutup, fokus kembali ke pemicu, `aria-labelledby`; `overscroll-behavior: contain` pada panel gulir. Diperiksa e2e per modal. |
| Formulir | Lulus | Galat di dekat isian dengan `aria-invalid`; fokus ke isian bertanda pertama (J-02b S-2, M-10 S-1); label klik; `Simpan` tidak dinonaktifkan sebelum permintaan berjalan. |
| URL dan Back | Lulus | Skema, periode, versi, tab, butir, halaman tabel, dan hasil aksi ada di URL; e2e menekan Back pada J-02, J-03b, J-04b. |

| Konten | Lulus | Label tombol, isian, dan pesan real use case persis (`docs/spesifikasi-ui.md`); tambahan prototipe dicatat di `docs/catatan-inkonsistensi.md` butir 17 dan 19 sampai 27. |

## Temuan dan perbaikan

| No | Temuan | Tindakan |
|---|---|---|
| 1 | Tombol `sm` di sel tabel setinggi 32 px (di bawah 44 px yang dianjurkan untuk sentuh). | Diperbaiki: `pointer-coarse:h-11` pada ukuran `sm` dan `md` di `button.tsx`; penunjuk halus tetap padat untuk tabel kerja. |
| 2 | `TombolUnduh` tidak meneruskan atribut seperti `aria-label` ke `<a>`; J-08 memakai teks `sr-only` sebagai nama aksesibel. | Dibiarkan: nama aksesibel sudah benar lewat `sr-only`; usulan meneruskan sisa props tidak mengubah perilaku. |
| 3 | Sebaran Beban dengan ratusan reviewer hanya menggulir di dalam wadah, tanpa virtualisasi. | Dibiarkan: ±130 baris pada skala nyata dan tabel usulan berhalaman 50 baris; tidak ada kendala kinerja pada uji skala 10.000 proposal. |
| 4 | Perpindahan layar lewat tautan internal Next tidak memicu `beforeunload` (J-02b, J-08b). | Dibiarkan dan dicatat (`catatan-inkonsistensi.md` butir 26); isian ditandai "Ada perubahan yang belum disimpan" dan koreksi butir tersimpan langsung. |
| 5 | Aturan CSS global `h1/h2/h3` tanpa `@layer` mengalahkan utilitas warna Tailwind di BIMA. | Dibiarkan: heading BIMA memakai `text-slate-900!`; dapat dihapus bila aturan dipindah ke `@layer base`. |
| 6 | E2E menemukan harapan usang: tombol "Lihat" pertama di Riwayat Versi adalah versi Terbit; pindah layar ke J-02b/J-03b mendarat di J-02/J-03; teks "Pengiriman ditahan" tidak ada lagi di J-06. | Aplikasi benar, tes disesuaikan (`e2e/jalankan.ts`). |

Tidak ada pelanggaran aturan `web-design-guidelines` yang tersisa selain butir 3 sampai 5 yang disengaja.
